Harness Firmware is the layer that loads before the work starts: standing rules, on-demand skills, and committed memory that survives the end of a session. Flash it onto a repo, and every session boots already knowing what the last one learned.

SECTION 01 · PERSISTENT MEMORY

Memory that survives power-off.

An agent with no durable memory relearns the same gotcha in every session. Here, each lesson gets a committed home in the repo itself. It travels to every machine, every sandbox, and both runtimes, and it is mounted before the work that needs it.

That cold-boot transcript is the template’s own recorded pitfall, dated 2026-07-18. /recall save wrote it once. /sync-starter can carry a generic lesson back to the template, so every future project boots with it too.

SECTION 03 · FLASH PROCEDURE

Add it to a repo you have, or spawn one that starts warm.

Path A drops the skill set into an existing project. Path B spawns a whole project with the full system: kernel, hooks, memory, and starter sync.

A · SKILLS ONLY

/plugin marketplace add ryanportfolio/Harness-Firmware
/plugin install claude-starter@claude-starter

Nothing else changes in your repo. It ships under its historical plugin id, claude-starter; skills arrive namespaced.

B · FULL TEMPLATE

  1. use this template on GitHub
  2. open the clone in Claude Code
  3. run /init-project

/init-project detects the stack and runs a short Q&A. Then it fills in the verification and deploy rules, seeds the memory files, and prunes what you won’t use before committing the setup.

SECTION 04 · TARGETS

One image, two runtimes.

The same firmware flashes to Claude Code and to Codex. Claude Code runs the full system. Codex gets its own rules file, AGENTS.md, written so Claude-only hooks and git automation never leak into it, and finds the same skills through thin generated adapter stubs. One source of truth, no duplicated playbooks.

SOURCE

Open, auditable, MIT.

The whole system is a public GitHub template. Forked skills carry their origins and licenses in PROVENANCE.md, notably Jesse Vincent’s superpowers set (MIT). Health is checkable: doctor.mjs audits hooks, skills, and adapter sync; context-weight.sh prices the resident layer.
