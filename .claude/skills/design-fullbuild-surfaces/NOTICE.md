# Notice and provenance

`design-fullbuild-surfaces` is homegrown for this repository and MIT, same as the repo (see the root `LICENSE`). It was synthesised by `forge-repo-ui-skill` from repository code plus seven externally reviewed sources.

No external skill text, code snippet, table, catalog, script, dataset, ruleset, configuration or license file was vendored. Every line in `SKILL.md` and `references/` is written from this repository's own code and reference library. Where an external source contributed an idea, the idea is restated in original wording and re-derived against local truth; where a source contradicted shipped local decisions, the local decision was kept and the conflict is recorded below.
